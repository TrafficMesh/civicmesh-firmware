# CivicMesh Edge Node Firmware

Python firmware for Raspberry Pi CM4 nodes.

**Status**: Phase 1 (coming Q3 2026)

## Modules
- camera_capture.py: GStreamer H.264 pipeline
- obd_interface.py: OBD-II speed reading
- gps_module.py: u-blox GPS integration
- edge_inference.py: TensorFlow Lite models
- uploader.py: Evidence compression and queuing

See civicmesh-hardware for hardware specs.
